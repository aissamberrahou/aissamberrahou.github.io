This course teaches object-oriented programming with C# and .NET, from language fundamentals to building desktop applications connected to a database.

## Prerequisites
- Basic programming in any language (variables, loops, functions)

## Tools
- [.NET SDK](https://dotnet.microsoft.com/download) with Visual Studio or Visual Studio Code

## Project
In groups, students build a complete management application (e.g. library, stock or student records) with a graphical interface and a database.
